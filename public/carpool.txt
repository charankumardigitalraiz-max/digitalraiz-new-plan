================================================================================
WAYFER API CURL COMMANDS - ADMIN CARPOOL MANAGEMENT (RIDES & BOOKINGS)
Base URL: http://localhost:5000/api/admin/carpool (or http://localhost:5001/api/admin/carpool)
================================================================================

All admin carpool endpoints require an active Bearer Token of a user with role 'admin'.

================================================================================
A. ADMIN RIDE MANAGEMENT
================================================================================

1. GET ALL RIDES (With pagination, status filtering, and keyword search)
--------------------------------------------------------------------------------
curl -X GET "http://localhost:5000/api/admin/carpool/rides?status=active&page=1&limit=20" \
  -H "Authorization: Bearer YOUR_ADMIN_TOKEN"

PowerShell:
Invoke-RestMethod -Uri "http://localhost:5000/api/admin/carpool/rides?status=active&page=1&limit=20" -Method Get -Headers @{"Authorization"="Bearer YOUR_ADMIN_TOKEN"}

3. UPDATE RIDE STATUS (active, completed, cancelled)
--------------------------------------------------------------------------------
curl -X PATCH http://localhost:5000/api/admin/carpool/rides/1/status \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_ADMIN_TOKEN" \
  -d '{
    "status": "cancelled"
  }'

PowerShell:
Invoke-RestMethod -Uri "http://localhost:5000/api/admin/carpool/rides/1/status" -Method Patch -Headers @{"Content-Type"="application/json"; "Authorization"="Bearer YOUR_ADMIN_TOKEN"} -Body '{"status":"cancelled"}'

Sample Response (200 OK):
{
  "status": "success",
  "message": "Ride status updated to 'cancelled' successfully",
  "data": {
    "ride": {
      "id": 1,
      "status": "cancelled",
      "updatedAt": "2026-10-23T14:40:00.000Z"
    }
  }
}


4. DELETE A RIDE (Admin Override)
--------------------------------------------------------------------------------
curl -X DELETE http://localhost:5000/api/admin/carpool/rides/1 \
  -H "Authorization: Bearer YOUR_ADMIN_TOKEN"

PowerShell:
Invoke-RestMethod -Uri "http://localhost:5000/api/admin/carpool/rides/1" -Method Delete -Headers @{"Authorization"="Bearer YOUR_ADMIN_TOKEN"}

Sample Response (200 OK):
{
  "status": "success",
  "message": "Ride deleted permanently by Admin"
}

8. CANCEL A BOOKING WITH AUTOMATIC SEAT RESTORATION TO RIDE

  -H "Authorization: Bearer YOUR_ADMIN_TOKEN"

PowerShell:
Invoke-RestMethod -Uri "http://localhost:5000/api/admin/carpool/bookings/1/cancel" -Method Post -Headers @{"Authorization"="Bearer YOUR_ADMIN_TOKEN"}
