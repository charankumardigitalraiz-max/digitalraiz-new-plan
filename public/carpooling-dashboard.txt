================================================================================
WAYFER API CURL COMMANDS - ADMIN CARPOOL DASHBOARD (ALL-IN-ONE API)
Base URL: http://localhost:5000/api/admin/carpool
================================================================================

All admin carpool endpoints require an active Bearer Token of a user with role 'admin'.

================================================================================
GET CARPOOL DASHBOARD OVERVIEW (ALL-IN-ONE)
================================================================================
Consolidates all carpool metrics, driver verification counts, expressway corridor
shares, timeframe analytics trends, and recent ride & booking activities into a
single unified response.

Method: GET
Endpoint: /api/admin/carpool/dashboard/overview

Query Parameters:
- timeframe (optional): '7D', '30D' (default), '90D', '12M'
- corridorLimit (optional): Number of top corridors to return (default: 5)

cURL Command:
curl -X GET "http://localhost:5000/api/admin/carpool/dashboard/overview?timeframe=30D&corridorLimit=5" \
  -H "Authorization: Bearer YOUR_ADMIN_TOKEN"

PowerShell:
Invoke-RestMethod -Uri "http://localhost:5000/api/admin/carpool/dashboard/overview?timeframe=30D&corridorLimit=5" -Method Get -Headers @{"Authorization"="Bearer YOUR_ADMIN_TOKEN"}
